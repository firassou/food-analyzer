# Real pen-mark photos

Drop photos of medicine boxes here to test the marks reading with `pnpm eval:marks`.

Name each one `<anything>__<answer>.jpg`, where the answer is what the pharmacist actually wrote:

- `none`: no handwriting
- `any1`: one line across the box (once a day, no set time)
- `1-0-1`: units in the morning, at midday and in the evening (`2-0-1`, `1-1-1`, `0.5-0-0.5`…)

These photos are git-ignored on purpose: they show someone's medicine. Crop out names, addresses and
batch numbers if you share one.
